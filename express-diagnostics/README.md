# Экспресс-диагностика AI на airl.kz/diagnostics

Бот, который опрашивает руководителя (5 полей знакомства + 8 вопросов), считает балл
AI-зрелости 4–16 (Starter / Developing / Advanced), боли и зоны роста. Заменил прежний
опрос сотрудников по коду группы. Исходник перенесён сюда из локального проекта
`express-diagnostics` (он же airl-express.web.app) 8 октября 2026.

`diagnostics.html` в корне репозитория собирается скриптом, руками его не правьте:

```sh
python3 express-diagnostics/build.py
```

## Файлы

| Файл | Что делает |
|---|---|
| `base-artifact.html` | Бот целиком: интерфейс, диалог, голос, экран «Спасибо» |
| `report.js` | Логика: вопросы, скоринг, уровни, боли, зоны роста, отчёт менеджера |
| `voice.js` | Распознавание и озвучка речи браузером |
| `delivery.js` | Что происходит после диагностики (ниже) |
| `build.py` | Вшивает `report.js`, `voice.js`, `delivery.js` в страницу и применяет настройки airl.kz |
| `fonts/` | Nunito Sans 400/700/800 для PDF, лицензия OFL (`fonts/OFL.txt`) |

## После диагностики

Клиент видит экран «Спасибо», результат приходит от менеджера. В Telegram-канал
(`AIRL_TELEGRAM` из `/firebase-bridge.js`) уходят по очереди:

1. Сводка для менеджера, код группы и ссылка «Отправить клиенту разбор в WhatsApp». Она
   открывает чат с номером, который клиент оставил на последнем шаге, и уже набранным
   абзацем-итогом. Если клиент оставил ник Telegram, вместо неё ссылка на его чат.
2. PDF-summary для клиента: балл и уровень, четыре оси, боли, зоны роста с первыми
   шагами, эффект, контакты. Его менеджер прикладывает в тот же чат.
3. Прежний HTML-отчёт для менеджера: триггер, сегмент, ICP, возражения.

WhatsApp не умеет писать сам без платного WhatsApp Business API, поэтому сообщение
клиенту отправляет менеджер, одним нажатием.

**Код группы.** Ссылка из заявки (`/diagnostics?code=AIRL7013`) открывает этого бота.
Код проверяется по `groups_public` и попадает в сводку («заявка: компания», «группа
закрыта», «такого кода нет»). Без кода бот тоже работает.

**PDF** собирается в браузере через pdfmake (cdnjs). pdfmake и шрифты весят почти 2 МБ,
поэтому начинают грузиться с первого клика на странице, а не при открытии.

## Где что менять

- Номер WhatsApp AIRL на экране «Спасибо»: `CFG.whatsapp` в `build.py`.
- Контакты и цвета в PDF, текст абзаца: `delivery.js`.
- Вопросы и логика: `report.js`.

После правки пересоберите страницу.
